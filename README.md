## For Omarchy

I run [Omarchy](https://omarchy.org) (Arch, Hyprland) and built the pieces I
missed from Windows.

- **[fcx](https://github.com/ShaKy8/fcx)** — a FreeCommander-style dual-pane
  file manager in Rust and GTK4, with FreeCommander XE's shortcuts so nothing
  has to be relearned.
- **[CLIP//NET](https://github.com/ShaKy8/clipnet)** — Ditto for Omarchy:
  every copy kept with all of its formats, Ctrl+' to search and paste.
- **SYS//NET** — a low-power system HUD painted into the ATMOS//NET
  wallpaper, in Quickshell. Private for now.
- **The rebuild kit** — my laptop as a repo: every package, /etc file and
  dotfile, and how to rebuild it. Private, because it's mine.

## How I build now

I work with Claude Code and Codex the way I used to work with a team: I
decide what should exist and why, they do most of the typing, and we argue
about the rest. Everything above has tests it runs on itself,
headless-browser gates for the things tests can't see, and a CLAUDE.md that
records the decisions and the traps so the next session, human or not,
doesn't relearn them. It is the most fun I've had in this field in years.
